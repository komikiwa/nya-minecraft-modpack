# моя супер крутая сборка для игры в майн 1.21.1

## список модов
- Fabric API — 0.97.0
- Sodium — 0.5.8
- Lithium — 0.12.0
- OpenToPublic — 1.3.1
- ... продолжение следует

## необходимо для игры в сборку
1. иметь компьютер
2. иметь legacy launcher (на официальном лаунчере ломается отображение скинов!!!!) 
3. иметь версию майнкрафта 1.21.1
4. скачать **Fabric Loader**.
5. скачать сборку с репозитория
6. закинуть в `.minecraft/mods`.
